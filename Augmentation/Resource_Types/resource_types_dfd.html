Resource Type Resolution Data Flow

How validate.records.resource_type gets corrected. Six scripts compare the MSP database against the SoilWise OGC catalogue, let the DOI registries break the tie, then write the answer back. Steps 15–17 and 42 touch only files in data/; only steps 18 and 19 write to the database.

msp-kh-dev.json→ msp_type_mismatches.csv→ ..._with_correct_type.csv→ validate.records

Overview

The whole resource-type flow. Steps 15–17 build the mismatch list, step 42 asks the DOI registries which side is right, and steps 18–19 write the decision back. The notebook and the script are two routes through the same step.
